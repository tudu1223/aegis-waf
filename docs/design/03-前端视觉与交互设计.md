## 1. 设计定位与原则

### 1.1 关键词

**深空黑底 · 精密网格 · 冷青主色 · 数据即视觉 · 克制的动效**

### 1.2 五条铁律

1. **暗色为唯一主题**：安全监控场景天然属于暗色，亮色主题一律不做。深色能让数据发光，是"高级感"的物理基础。
2. **留白优于堆砌**：宁可少放一个图表，也要保证呼吸感。廉价感的第一来源是元素塞满屏幕。
3. **动效服务于信息**：只在"状态变化"时使用动效（新事件飞入、威胁等级跃迁、AST 子树生长）。禁止无意义的常驻旋转、闪烁、粒子。
4. **色彩即语义**：颜色只用来编码威胁等级与状态���不做装饰性配色。全局仅一个主色 + 四个语义色。
5. **数字必须是等宽字体**：所有指标数字使用等宽数字字体，避免跳动时宽度抖动——这是专业感的关键细节，绝大多数学生作品会忽略。

## 2. 设计令牌（Design Tokens）

### 2.1 色彩系统

```scss
// ============ 背景层次（五级景深，营造空间感）============

$bg-base:        #0A0E14;   // 主容器背景
$bg-surface:     #0F141C;   // 卡片背景
$bg-elevated:    #151C26;   // 悬浮元素、弹层
$bg-overlay:     #1B2430;   // 高亮行、hover 态

// ============ 主色：冷青（Cyan）============
// 选择理由：冷青是监控/雷达/终端的经典语义色，
//          冷静专业，且在深色底上有极佳的发光观感
$primary:        #00D9FF;
$primary-dim:    #0891A8;   // 次要状态

$primary-faint:  rgba(0, 217, 255, 0.08);   // 背景微光

// ============ 语义色：威胁等级 ============
$critical:       #FF2E5B;   // 严重  洋红红（比纯红更高级，不刺眼）
$high:           #FF6B35;   // 高危  炽橙

$low:            #4ADE80;   // 低危  薄荷绿

$safe:           #10E0A0;   // 安全  青绿（区别于 low，用于"已拦截/正常"）

$text-primary:   #E8EEF5;   // 主文本（不用纯白，降低刺目）
$text-secondary: #8B98A9;   // 次要文本
```

## 3. 全局视觉基底

### 3.1 背景层构造（三层叠加，营造深度）

```scss
.app-root {
  position: relative;
  background: $bg-void;

  // 第一层：精密网格（营造"坐标系/雷达"的秩序感）

                #000 30%, transparent 75%);   // 顶部清晰，向下淡出
  }

  // 第二层：顶部光晕（视线引导，画面不平）
  &::after {
    content: ''; position: fixed; inset: 0; pointer-events: none;
    background: radial-gradient(ellipse 80% 50% at 50% -10%,
                rgba(0,217,255,0.10) 0%, transparent 60%);
  }
}

// 第三层：极细噪点，消除大面积纯色的"塑料感" ★ 高级感关键细节
.app-root .noise-layer {
  position: fixed; inset: 0; pointer-events: none;
  opacity: 0.02; mix-blend-mode: overlay;
  background-image: url("data:image/svg+xml,...fractalNoise...");
}
```

> 噪点层是区分"学生作品"与"商业级设计"的隐形细节。纯色渐变在大屏上会显得廉价，2% 的噪点能立刻提升质感。

- 攻击柱出现时带 200ms 生长动画 + 顶部发光点

**节点样式**：

| 状态 | 填充 | 描边 | 文字 | 特效 |
|---|---|---|---|---|
| `normal` | `rgba(0,217,255,0.08)` | `$primary-dim` 1px | `$text-primary` | 无 |
| `injected` | `rgba(255,46,91,0.15)` | `$critical` 1.5px | `#FFD5DE` | **脉冲光晕循环** |
| `removed` | `rgba(139,152,169,0.06)` | `$text-tertiary` 1px 虚线 | `$text-tertiary` | 半透明 0.5 |
| `hover` | 提亮 20% | 加粗 | — | 显示 tooltip |

- 节点形状：圆角矩形 `$r-sm`，宽度自适应文本，高度 32px
- 布局：G6 `compactBox` 紧凑树布局，方向 `LR`（从左到右，比自上而下更适合宽屏）
- 连线：贝塞尔曲线，`normal` 用 `$primary-dim` 0.6px；通向 `injected` 节点的边用 `$critical` 1.2px

**注入节点脉冲动效**（核心视觉）：
```javascript
// G6 自定义节点，注入节点持续脉冲——这是"红色子树破土而出"的实现
graph.node(node => {
  if (node.status === 'injected') {
    return {
      style: { fill: 'rgba(255,46,91,0.15)', stroke: '#FF2E5B', lineWidth: 1.5,
               shadowColor: '#FF2E5B', shadowBlur: 12 },
      animate: { type: 'pulse', duration: 1600, repeat: true,
                 // shadowBlur 在 8 ↔ 24 之间呼吸
                 easing: 'easeInOutSine' }
    };
  }
});
```

**入场动效**（演示时的关键）：
1. 基线结构先渲染（青色），逐级展开，每级延迟 60ms
2. 停顿 300ms
3. 注入子树从父节点位置"生长"出来：`scale 0 → 1` + `opacity 0 → 1`，$ease-spring，600ms
4. 生长完成后开始脉冲循环
5. 同时右侧"变异节点"卡片依次滑入

> 这段 4 秒的动画序列就是整个答辩最有冲击力的瞬间，务必打磨。

### 6.3 SQL 代码对照区

- 使用等宽字体，行号栏 `$text-tertiary`
- 基线 SQL 与实际 SQL 并排（split view）
- 注入片段用 `rgba(255,46,91,0.2)` 背景 + `$critical` 左边框标记
- 关键字语法高亮：关键字 `$primary`、字符串 `$medium`、占位符 `?` 用 `$safe`、危险函数 `$critical` 加粗

## 8. 关键交互细节（提升精致度）

| 细节 | 规格 | 理由 |
|---|---|---|
| 数字滚动 | CountUp，$dur-slow，等宽字体 | 避免生硬跳变 |
| 骨架屏 | 所有异步区域使用 shimmer 骨架，不用 loading 转圈 | 转圈显得廉价 |
| 空状态 | 插画 + 说明文字 + 引导按钮，不留白板 | 完整度体现 |
| 表格 hover | 整行背景 `$bg-overlay`，$dur-instant | 即时反馈 |
| 按钮按下 | `scale(0.97)`，$dur-instant | 物理反馈感 |
| Tooltip | 深色玻璃卡 + 1px 主色边 + 8px 偏移 | 统一质感 |
| 滚动条 | 自定义 6px 宽，`$border-default`，hover 转 `$primary-dim` | 默认滚动条破坏暗色主题 |
| 焦点环 | `outline: 2px solid $primary-glow; outline-offset: 2px` | 可访问性 + 专业度 |
| 页面切换 | 内容区淡入 + `translateY(8px→0)`，$dur-normal | 连贯感 |
| 状态灯 | 2 秒呼吸，`opacity .5↔1`，仅系统状态灯保留常驻动效 | 唯一的常驻动效例外 |
