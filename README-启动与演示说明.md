# AEGIS · 启动与演示说明

基于抽象语法树结构指纹的 Web 攻击语义检测平台

## 环境要求

- JDK 17+
- Node.js 18+（仅前端需要）

## 启动顺序

| 顺序 | 脚本 | 服务 | 端口 |
|---|---|---|---|
| 1 | 1-启动控制台.bat | 控制台服务 | 8080 |
| 2 | 2-启动靶场(含RASP探针).bat | 靶场 + RASP 探针 | 8090 |
| 3 | 3-启动安全网关.bat | 安全网关 | 8000 |
| 4 | 4-启动前端.bat | 可视化前端 | 5173 |

等待约 30 秒全部就绪后，浏览器打开 http://localhost:5173

## 演示要点

1. **态势总览**：右上角切换防护模式（关闭/监控/拦截）
2. **攻防演练台**：选择攻击通道，点击「▶ 发起」观察拦截
3. **语义分析**：查看 SQL 语法树差分（红色为注入变异结构）
4. **威胁事件**：执行「校验审计链」验证日志完整性
5. **对比演示**：关闭防护后发起攻击→恢复拦截→再次阻断
